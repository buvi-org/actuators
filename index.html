R0 / Reference study
01 / WHAT WE HAVE

A dimensionally faithful reference

The CubeMars STEP assembly is converted to GLB in metres. Component identities, placement and quantities are preserved. The measured envelope is Ø98 × 38.5 mm.

43 leaf instances contain 54 solids. Twelve solids belong to the simplified driver assembly; these are not twelve identified electronic parts.

02 / WHAT IS MISSING

The working motor and gear details

Stator laminations, coils, rotor magnetic steel and magnets are not modelled. Planet gears, pins, planet bearings and ring teeth are also absent. Their dimensions cannot be recovered from this STEP file.

Material specifications, tolerances, heat treatment, winding data and a PCB placement BOM still require engineering or physical measurements.

03 / FIRST DESIGN RELEASE

Define the electromagnetic stack

Use the published 36 slots, 21 pole pairs and 100 KV as reference targets. Select stack geometry, steel, air gap, magnet grade and a winding layout using electromagnetic and thermal analysis.

Measure terminal resistance, inductance and back EMF under documented conditions. Confirm turns and wire size with a physical reference if reverse engineering.

04 / MECHANICAL RELEASE

Close the torque path

Choose a 9:1 gear architecture, then calculate tooth contact/root stress, pin bending, carrier stiffness and bearing life. Specify fits, lubrication, backlash and output load cases.

Check all interferences and tolerance stacks in solid CAD before generating machining drawings.

05 / ELECTRONICS & TEST

Validate the complete assembly

Resolve the driver revision and current conventions. Define regeneration handling, current limits, temperature sensing and firmware. A custom driver requires a schematic and electronic BOM.

Measure torque-speed performance, efficiency, temperature rise, backlash, noise and endurance. Published CubeMars performance does not certify a Primeform build.

06 / PUBLIC DEVELOPMENT

Keep the provenance visible

CubeMars owns the manufacturer reference geometry. Primeform's conversion code and engineering notes are tracked separately. This project has not yet selected licenses for its own work.

Publishing a reference conversion does not make the manufacturer's design an original Primeform design or establish an open-hardware license.
